# RambutanSmartGarden

A smart rambutan garden management web application.

## Tech Stack

- Backend: ASP.NET Core Web API (.NET 10)
- Frontend: React JS + Vite
- Styling: CSS
- Database: SQL Server + EF Core
- Realtime: SignalR
- Architecture: Feature-First + Layered
- Platform: Progressive Web App (PWA)

## Features

- Garden and tree management
- Tree health and pest monitoring
- Care activities and task scheduling
- Irrigation management
- Harvest and financial management
- IoT irrigation simulator
